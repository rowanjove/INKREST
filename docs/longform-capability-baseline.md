# 栖墨长篇能力基线（M0 冻结）

> 日期：2026-08-22
> 对应计划：桌面 `2026-08-22-longform-scale-optimization-master-plan.md`
> 验收环境：Python 3.11/3.12。禁止用 Python 3.8 作为验收环境。

## 1. 现有工作区边界

开始本计划时，仓库 `main` 上仍有未提交的质量中心改动（RenderContract、候选集、事件记忆、QualityCenter UI 等）。本里程碑只新增长篇规模契约、分页、流式导出和基准脚手架，不覆盖那些文件的质量语义。

## 2. 体量口径（冻结前）

| 档位 | 设计硬上限 | 验证等级 |
|---|---:|---|
| micro | 3 | 设计支持 + 自动化回归 |
| short | 20 | 设计支持 + 自动化回归 |
| medium | 100 | 设计支持 + 自动化回归 |
| long | 500 | 正式支持：回归、恢复、导出 |
| epic | 3000 | 本轮起工程路径；尚未宣称真实模型长跑验收 |
| infinite | 999999 | 5000 章为阶段性软目标；不承诺一次生成 5000 章 |

三个不得再混用的数字：

- `scale_hard_max`：档位硬上限。epic 保持 3000；5000 章必须用 infinite。
- `project_soft_target`：本书当前目标章数，无限连载里只是阶段性目标。
- `run_chapter_budget`：单次运行最多生成的章数，默认 20，硬顶 200。

## 3. 当前 API / 前端 / 导出

- 正文与发布目录：服务端 `offset/limit/query`，默认每页 100；正文只在选中章节时读取。
- TXT/Markdown：按 SQLite 文稿真源逐章流式写入临时文件后原子替换。发布中心 HTTP 导出已改为
  任务表后台作业，提供进度、取消、失败清理和完成后下载；旧 `/api/export` 兼容端点仍保持同步。
- DOCX/EPUB/PDF：仍可物化 `PublicationBook`，内存约束单独记录，不与纯文本阈值混用。
- 备份：流式压缩 + 文件数/单文件/总大小上限。
- SQLite 向量 fallback 扫描上限 50,000，使用 cursor 有界扫描并通过 readiness 暴露
  `scanned_rows/scan_cap/capped/degraded`；向量重建已接入可取消、可恢复后台 worker。
- V2 reset backup 与普通/批量 ZIP 都执行文件数、单文件、总展开量和下载体积限制；V2 backup
  通过 `/api/projects/import-zip` 时先校验 manifest/hash。

## 4. 功能开关与回滚

见 `novel_agent/control/longform_flags.py`。可在项目 `pipeline.yaml` 的 `runtime.longform_flags` 覆盖。

| 开关 | 默认 | 回滚 |
|---|---|---|
| `m1_scale_budget` | 开 | 体量校验调用点保持开启；该开关因请求模型先于项目根目录校验，当前仅作为预留兼容标记 |
| `m1_catalog_pagination` | 开 | 关闭后正文/发布服务回退到全量过滤目录，便于故障诊断；默认必须保持开启 |
| `m1_streaming_export` | 开 | 关闭后仍走后台兼容任务，但关闭逐章进度回调；旧 `/api/export` 不受影响 |
| `m1_vector_readiness` | 开 | 关闭后 status 明确返回 disabled，不改变底层扫描上限 |

M2–M5 默认关闭，避免检索/正典/评测/候选路径在用户未确认时改变生成行为；对应代码和
离线回归已具备，真实模型长跑仍需显式启动。

## 5. 明确不宣称

- 现有系统尚未真实生成并验收 3000/5000 章。
- 5000 章压力测试属于合成工程验证，不等于模型质量验收。
- 真实 20/50/100 章长跑必须由用户显式启动，默认测试和页面加载不得触发生成。
