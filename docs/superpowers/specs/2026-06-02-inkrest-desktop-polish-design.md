# 栖墨桌面端细节修订设计

## 目标

修正 Windows 任务栏图标白边，精简宠物状态面板的中止按钮，为任务流水日志增加手动刷新入口，并优化侧栏品牌区的中英文排版。

## 视觉方案

侧栏品牌区采用 A 方案：

- `栖墨` 与 `INKREST` 同行展示。
- `栖墨` 是中文主品牌，使用偏暖白色、较大字号和轻微字间距。
- `INKREST` 是金色小型英文副标，使用衬线字体和更明显的字间距。
- 第二行只保留 `智能长篇写作空间`，避免窄侧栏换行。
- 图标保持现有书本视觉，但桌面 PNG 和 ICO 的画布外缘必须透明。

## 交互调整

- 宠物状态卡的 `中止当前章节生成` 改为 `中止`，行为不变。
- 任务流水日志保留现有自动轮询机制，并在标题区增加手动 `刷新` 按钮。
- 手动刷新调用章节 store 的 `fetchTasks()`，刷新过程中按钮显示加载状态。

## 验证

- 静态契约测试覆盖透明图标、按钮文案、日志刷新入口和品牌区结构。
- 运行完整 Python 测试和前端构建。
- 浏览器运行态检查侧栏品牌区与任务流水日志。
- 重新封装 Windows 安装包和便携版。
