## 二、平台分层：你该怎么选

### 1. 第一梯队：上限最高，但最卷

#### **起点中文网**

这是男频长期主义的主战场。你要是想写出真正能沉淀作者名、IP、粉丝和版权的书，起点仍然是核心平台之一。阅文作家专区是阅文旗下创作入口，覆盖起点、QQ阅读、红袖、潇湘、云起等站点。([腾讯写作](https://write.qq.com/?utm_source=chatgpt.com))

**适合：**

| 类型 | 适配度 |
|---|---:|
| 玄幻升级 | 高 |
| 仙侠修真 | 高 |
| 科幻/诸天/无限 | 高 |
| 都市异能/神豪 | 中高 |
| 历史文 | 高，但门槛高 |
| 轻松日常 | 中 |
| 小白爽文 | 中低，除非节奏极强 |
| AI批量文 | 低，很容易死 |

**优点：**

起点的核心不是“新人友好”，而是**天花板高**。同样一本书，如果真能起来，起点的订阅、月票、打赏、版权、作者名望综合价值非常强。并且付费站最大的好处是数据清楚：收藏、追读、订阅、章节掉点都能逼着作者成长。

**缺点：**

新人不要被“大神都在起点”骗了。起点不是不能投，而是**它惩罚平庸非常狠**。你前3万字不抓人，追读起不来，后面写100万字也大概率单机。

**适合你的策略：**

如果你是第一次写商业网文，不建议把第一本重注压起点。可以拿一本文练结构、节奏、开篇；等你能稳定写出“前3章有钩子、前10章有爽点、前30章形成期待”的东西，再冲起点。

**缺点：**

1. 主角是谁；
2. 他有什么惨/爽/奇；

适合轻小说、校园、异世界、二次元恋爱、变嫁、幻想冒险。相比刺猬猫，菠萝包更“轻小说气质”。

**适合你写：**

- 日轻式标题；
- 角色卖点强；
- 人设比世界观更重要；
- 女主/男主互动密集；
- 章节轻快，不搞大段设定说明。

**不适合：**

传统玄幻升级、严肃历史、复杂权谋、硬核科幻。

---

### 7. 短篇/中短篇平台：现金流最快

#### **知乎盐选**

知乎盐选适合短篇故事，不是传统长篇网文。知乎故事的核心是：**问题感、钩子、反转、情绪爆点、结尾爽感**。公开投稿经验贴提到，知乎短篇常见做法是通过盐选作者平台创建作品，填写标题、标签、金句，上传约8000—15000字稿件；这类信息属于作者经验，不等同于官方永久规则。([zhihu.com](https://www.zhihu.com/question/10058203047?utm_source=chatgpt.com))

**适合：**

| 类型 | 适配度 |
|---|---:|
| 现言虐恋 | 高 |
| 复仇爽文 | 高 |
| 家庭伦理 | 高 |
| 悬疑反转 | 高 |
| 重生短篇 | 高 |
| 无限流短篇 | 中高 |
| 长篇玄幻 | 低 |
| 慢热群像 | 低 |

**优点：**

短篇训练价值极高。你能快速学会：

- 开头三句抓人；
- 每几百字一个小钩子；
- 每2000字一个反转；
- 结尾情绪释放。

**缺点：**

盐选不是长篇生态。你在知乎短篇练出来的是“强钩子短篇能力”，不等于你能写200万字长篇。

---

#### **阅见文学等短篇买断平台**

阅见文学2025作者福利页显示，其短篇投稿方向包括第一人称、快节奏、多反转、代入感强；超短篇1万到2万字，中短篇3万到5万字；收稿方向包括世情爽文、世情悬疑、现言甜爽、现言虐恋、古言虐文、悬疑灵异等；短篇买断/保底千字30元起，纯分成可享受渠道四六或三七分成。([yuejianwenxue.com](https://www.yuejianwenxue.com/fuli?utm_source=chatgpt.com))

**适合：**

- 你想先赚钱；
- 你能批量生产短篇；
- 你不太在乎单篇版权长期价值；
- 你想往短剧剧本转。

**缺点很直接：**

买断钱来得快，但作品很可能不属于你了。你要看清楚是**信息网络传播权、独家、全版权、改编权、短剧权、音频权、海外权**到底卖了哪些。

## 四、按目标选平台

### 目标1：我就是新人，想第一本尽快有数据

优先级：

1. **番茄**
2. **七猫**
3. **飞卢**
4. **知乎盐选短篇**
5. **17K**

原因：这些平台反馈快。你别第一本就幻想“我要做IP宇宙”。第一本最重要的是知道自己能不能：

- 日更4000；
- 写满30万字不崩；
- 开头能不能留住读者；
- 爽点能不能持续供应；
- 编辑看不看得上。

---

### 目标2：我想长期当职业作者

优先级：

1. 男频：**起点 > 番茄/七猫 > 纵横/17K > 飞卢**
2. 女频：**晋江 > 潇湘/红袖/云起 > 番茄/七猫 > 知乎短篇**
3. 二次元：**刺猬猫/菠萝包/飞卢 > 起点轻小说**

职业作者看的是长期资产：

| 资产 | 免费站 | 付费站 |
|---|---:|---:|
| 快速流量 | 强 | 中 |
| 作者品牌 | 弱到中 | 强 |
| 订阅反馈 | 弱 | 强 |
| 爆款概率 | 中高 | 中 |
| 稳定现金流 | 看算法 | 看订阅和老读者 |
| IP沉淀 | 不稳定 | 更强 |

---

### 目标3：我想赚快钱，不想熬百万字

优先级：

1. **知乎盐选**
2. **阅见文学等短篇买断**
3. **短剧征稿**
4. **番茄短篇/中篇尝试**
5. **公众号故事号/小程序故事平台**

你要写：

- 复仇；
- 真假千金；
- 重生虐渣；
- 婚恋背叛；
- 家庭伦理；
- 悬疑反转；
- 第一人称强代入。

不要写：

- 大世界观；
- 慢热群像；
- 复杂设定；
- 20章才进入主线的东西。

短篇平台不吃这个。

---

### 目标4：我想写AI辅助网文

现实一点：  
**AI辅助最适合番茄、七猫、短篇平台、部分飞卢套路文。**  
**最不适合晋江、起点精品向、强作者风格文。**

因为AI容易写出：

- 套话；
- 情绪假；
- 人设漂；
- 爽点重复；
- 章节水；
- 伏笔断；
- 对话没有人味。

如果你用AI，平台选择上应该偏向：

| AI辅助程度 | 适合平台 |
|---|---|
| 高度AI批量 | 番茄试水、短篇买断，但风险大 |
| AI做大纲+人工写正文 | 起点、晋江、番茄、七猫都可 |
| AI润色/检查设定 | 所有平台 |
| AI生成敏感词检查 | 所有平台 |
| AI写整章直接发 | 不建议，质量和平台风控都可能出事 |

## 五、各平台投稿/签约重点

### 起点/阅文系

**投稿方式：**  
通过阅文作家专区创建作品、发书、等待编辑审核或达到条件后申请签约。阅文作家专区是统一创作入口。([腾讯写作](https://write.qq.com/?utm_source=chatgpt.com))

**你要准备：**

- 书名；
- 简介；
- 前3万字；
- 完整大纲；
- 金手指说明；
- 预计字数；
- 世界观/人物关系；
- 后续商业卖点。

**重点：**  
起点不是看你“文笔多好”，而是看你有没有持续制造期待的能力。追读是核心。

---

### 番茄

**投稿方式：**  
番茄小说网/作家后台创建作品。第三方投稿攻略普遍提到番茄作品达到约2万字可申请签约，但具体门槛以后台显示为准。([推文手圈](https://www.tuiwenshouquan.com/h-nd-346.html?utm_source=chatgpt.com))

**你要准备：**

- 强题材标题；
- 极短简介；
- 前2万字；
- 8万字前后的推荐承接；
- 日更4000以上的存稿能力。

**重点：**  
番茄不是“写得好就行”，而是**开头必须让算法看见留存**。

---

### 七猫

**投稿方式：**  
七猫中文网作者入口/编辑投稿/后台申请。

**你要准备：**

- 3万字左右正文；
- 商业大纲；
- 题材标签；
- 保底诉求；
- 类似爆款对标。

**重点：**  
七猫要的是“可运营、可持续、可转化”的书。编辑判断很重要。

---

### 飞卢

**投稿方式：**  
飞卢作者中心/飞卢作家助手。应用宝页面显示飞卢作家助手支持离线写作、云端同步、发布、收益查询、稿费申请等功能。([腾讯应用宝](https://sj.qq.com/appdetail/com.faloo.authorhelper?utm_source=chatgpt.com))

**你要准备：**

- 标题就要带爽点；
- 简介直接抛设定；
- 前10章密集爆点；
- 每章结尾留钩子；
- 每天6000—10000字更适合。

**重点：**  
飞卢慢不得。你第一章如果还在介绍世界观，基本已经输一半。

---

### 晋江

**投稿方式：**  
晋江注册作者、创建作品、发文、申请签约或等编辑联系。

**你要准备：**

- 文案；
- 人设；
- CP关系；
- 情绪线；
- 标签；
- 前几章氛围；
- 稳定更新计划。

**重点：**  
晋江文案非常关键。很多时候文案比第一章还决定第一波点击。

---

### 知乎盐选/短篇

**投稿方式：**  
盐选作者平台、官方征稿、编辑内投、短篇故事投稿渠道。

**你要准备：**

- 8000—15000字试稿；
- 完整3万字左右成稿；
- 前300字钩子；
- 每2000字反转；
- 明确情绪卖点。

**重点：**  
知乎短篇不是“小说开头”，而是“问题答案式故事”。你要像讲一个让人停不下来的瓜。

---

## 六、签约合同重点：这个比平台更重要

你投平台前，必须盯这几个词。

| 条款 | 你要看什么 |
|---|---|
| 独家/非独家 | 这本书能不能发别处 |
| 作者约/作品约 | 是只签这本，还是你这个人未来作品也受限 |
| 信息网络传播权 | 平台能不能网络发布 |
| 全版权 | 是否包括影视、漫画、游戏、短剧、有声、出版、海外 |
| 买断 | 是稿费买断，还是版权全卖 |
| 保底 | 是真保底，还是“保底+超出分成” |
| 分成比例 | 本站、渠道、广告、有声、版权是否分别计算 |
| 完本要求 | 多少字完本才结清 |
| 断更惩罚 | 断更几天取消福利 |
| 结算周期 | 月结、季结、完结后结 |
| 解约条件 | 扑街后能不能拿回版权 |
| AI条款 | 是否禁止AI生成或要求声明 |

一句话：  
**新人最容易死在“看见保底就签”。**  
保底不是白拿的，很多时候你用版权、更新义务、排他性换来的。

## 七、我的直接建议

### 如果你现在还没稳定写完过一本

别去起点硬冲。  
更合理路线：

**路线A：免费站练级**

1. 番茄开一本强设定爽文；
2. 写到30万字看数据；
3. 学会留存、节奏、完读；
4. 第二本投七猫或继续番茄；
5. 第三本再考虑起点/纵横。

适合你写男频脑洞、都市、系统、玄幻爽文。

---

**路线B：短篇现金流**

1. 先写5篇知乎/短篇平台故事；
2. 每篇1万—3万字；
3. 练钩子、反转、情绪；
4. 能过稿后批量写；
5. 再把高反馈题材扩成长篇。

适合你想快速验证AI辅助写作、想先赚小钱。

---

**路线C：长期IP路线**

1. 先用番茄/七猫/17K练一本；
2. 总结数据；
3. 重新设计世界观和人物；
4. 冲起点/晋江/潇湘；
5. 做系列化。

适合你真想长期做职业作者。

## 十、一句话结论

**新人别迷信“大平台”。你第一本书的目标不是封神，是验证自己能不能商业化。**

最优策略：

- **男频小白：番茄/飞卢/七猫三选一。**
- **女频小白：番茄/七猫/晋江按题材选。**
- **短篇赚钱：知乎盐选/阅见/短剧向。**
- **长期IP：起点/晋江/潇湘/纵横。**
- **二次元：刺猬猫/菠萝包/飞卢。**

真正狠的做法是：  
**先用短篇练钩子，用番茄练留存，用飞卢练节奏，最后再去起点或晋江做长期品牌。**
