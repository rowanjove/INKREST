# 网文去AI味写作规范

> 面向自动化网文生成系统，从写作结构和语言层面消除AI生成痕迹。
> 核心原则：AI的问题不是"用词太好"，是"太均匀"——全程匀速出力，每句话都合格，读起来反而像背课文。

---

## 一、句式规范：用具体替代抽象

### 问题根源

AI天然倾向于用抽象名词描述感受，而不是写具体发生了什么。

### 禁用句式清单

```
他的眼神中闪烁着复杂的光芒。
她的心中涌起一股难以言说的情绪。
空气中弥漫着紧张的气息。
这一刻，时间仿佛静止了。
他深吸一口气，缓缓开口。
一股莫名的情绪涌上心头。
她感到无比[复杂/痛苦/震惊]。
```

共同特征：说了等于没说，"复杂"在哪里？"难以言说"就别写。

### 正确写法

用具体动作、细节、环境承载情绪，不用抽象词语描述：

| 禁用写法 | 替换方向 |
|---------|---------|
| 眼神中闪烁着复杂的光芒 | 他看了她一眼，没说话，转头倒了杯水 |
| 心中涌起难以言说的情绪 | 她把手机扣在桌上，屏幕朝下 |
| 空气中弥漫着紧张的气息 | 没人说话。窗户在响，没人去关 |
| 时间仿佛静止了 | （直接删掉，用沉默的行为替代） |

### 执行规则

- **禁止**在正文中出现"复杂/难以言说/莫名/无比"等抽象修饰词
- **禁止**用"感到/感受到/涌起"等动词直接接情绪名词
- **要求**每个情绪场景至少有一个具体的身体反应或行为动作

## 二、节奏规范：学会"偷懒"

### 问题根源

AI每个场景都认真交代，详略完全一样。人写网文，重要的地方用力，不重要的地方一笔带过。

### 禁用节奏模式

```
两人来到了饭馆。他们找了一个靠窗的位置坐下。
服务员走过来，递上了菜单。两人点了几道菜，
等待的过程中，他们聊起了最近发生的事情。
```

问题：过渡场景和核心场景用同等篇幅，读者无法判断什么重要。

### 正确写法

```
找了个靠窗的位置，菜随便点的，
他一直在想刚才那句话是什么意思。
```

省掉不重要的过程，把空间留给真正重要的内容。

### 场景详略对照表

| 场景类型 | 应有篇幅 | 写法要求 |
|---------|---------|---------|
| 爆发章核心冲突 | 充分展开 | 细节丰富，节奏慢 |
| 铺垫章日常过渡 | 一两句带过 | 压缩到最少，不展开 |
| 蓄力章压迫感 | 中等，留白多 | 细节选择要有压迫感 |
| 过渡章时间推进 | 极简 | 直接跳过，用一句话交代结果 |

### 执行规则

- Planner 在场景任务里标注场景类型，Writer 按类型选择详略模式
- **铺垫/过渡场景**：禁止展开环境描写和心理描写，只写结果
- **爆发场景**：允许放慢节奏，细化动作和细节

## 三、对话规范：说一半，不说全

### 问题根源

AI对话每个人说话都太完整、太礼貌、信息量太精准，像在做汇报。

### 禁用对话模式

```
"我认为我们现在面临的最大问题，是如何在有限的
时间内完成这项任务。"李明沉声说道。

"你说得有道理，我们需要尽快制定一个可行的计划。"
王芳点头赞同。
```

问题：每句话都是完整陈述，没有停顿、打断、答非所问。

### 正确写法

```
"这事儿悬。"李明说。
"嗯。"
"你有数吗？"
王芳没答，看了他一眼。
```

### 对话规则

**信息缺省**：角色不需要把话说完整，说一半让读者补

**打断/转移**：
```
"你知道那天——"
"我不想聊这个。"
```

**答非所问**：
```
"你去哪了？"
"外面风挺大。"
```

**沉默也是对话**：
```
她问了，他没回答。
过了一会儿，他把烟掐灭了。
```

### 执行规则

- **禁止**角色在单次对话中完整陈述观点（超过3句连续发言视为违规）
- **要求**每段对话至少有一处信息缺省、打断或答非所问
- **禁止**对话结束后用旁白直接解释角色的意思（让读者自己理解）
- **禁止**对话动词滥用"沉声/轻声/柔声说道"，默认用"说"或不用动词

## 四、情绪规范：制造而不是告知

### 问题根源

这是AI网文最致命的问题。AI把情绪直接说出来，读者知道"应该难过"，但自己不难过。

### 两种写法的本质区别

**告知型（AI）**：
```
看到这一幕，她感到无比心痛。
泪水在她的眼眶中打转，她努力忍住，
却还是忍不住流了下来。
```

直接告诉读者情绪是什么，读者被动接收。

**制造型（人）**：
```
她把手机屏幕朝下扣在桌上。
然后去厨房倒了杯水，
水还没凉，她就一口喝完了。
```

不说难过，但读者难过。

### 情绪→行为转换对照

| 情绪 | 禁用写法 | 替换写法方向 |
|-----|---------|------------|
| 震惊 | 她感到无比震惊 | 她愣了一下，把筷子放下了 |
| 愤怒 | 愤怒在他心中燃烧 | 他把文件夹合上，力气比平时大了一点 |
| 紧张 | 她感到紧张和不安 | 她理了两次领子，都没理好 |
| 悲伤 | 悲伤涌上心头 | 她把窗帘拉上，没开灯 |
| 委屈 | 她感到委屈极了 | 她说"没事"，然后去洗碗了，碗是干净的 |

### 执行规则

- **核心规则**：禁止直接写角色的情绪感受，所有情绪必须通过身体反应、行为选择、环境细节来呈现
- **禁止词汇**：感到/感受到/涌起/充满/无比/极了/心中/内心 + 任何情绪词
- **要求**：每个情绪场景必须有至少一个具体的身体反应或不合逻辑的细节行为（"水没凉就喝完"这类）

---

## 五、结尾规范：每章制造缺口

### 问题根源

AI天然倾向于把每章写成完整的小故事，结尾有终结感。网文正确节奏是每章结尾制造新的缺口。

### 禁用结尾模式

```
这场争斗终于落下帷幕。他站在废墟之上，望着远处的天际，
心中充满了感慨。未来的路还很长，但他已经做好了准备。
```

问题：总结式/感慨式结尾，读者可以合上书睡觉了。

### 三种有效钩子

**信息钩**（揭露新信息，颠覆前文认知）：
```
"对了，"她走到门口，回头，
"上次的事，不是我做的。"
门关上了。
```

**行动钩**（角色做出行动，读者不知道结果）：
```
他看完最后一行字，把信叠好。
然后拿起了电话。
```

**反转钩**（出现意外的人/事，打破读者预期）：
```
人群散去之后，角落里一个人站起来，
拍了拍身上的土。
是他。
```

### 执行规则

- 第三层章节序列的 `hook` 字段强制填写，不允许为空
- **禁止**使用感慨式结尾（"他望着远方，心中充满了……"）
- **禁止**使用总结式结尾（"这一切，终于结束了"）
- **禁止**使用决心式结尾（"他已经做好了准备"）
- **要求**每章结尾必须属于信息钩/行动钩/反转钩之一

## 六、在生成流水线中的落地位置

```
Planner
  ├── 标注每个场景的详略权重（决定哪里该偷懒）
  └── 标注章节类型（铺垫/蓄力/爆发/过渡）

Writer
  ├── 执行禁用句式清单
  ├── 执行对话规则（信息缺省/打断/答非所问）
  ├── 执行情绪规则（行为替代感受，核心规则）
  └── 执行章节结尾钩子要求

StyleEditor
  ├── 扫描抽象情绪词 → 标记退回重写
  ├── 检查对话完整度 → 过于完整则退回
  └── 检查章节结尾类型 → 总结式/感慨式退回

Auditor（增加AI味检测维度）
  ├── 统计抽象情绪词密度（超过阈值标记高风险）
  ├── 检查对话中完整陈述比例
  └── 检查章节结尾是否属于有效钩子类型
```

---

## 七、优先级

如果只能改一件事，改这个：

> **禁止Writer直接写角色的情绪感受，所有情绪必须通过身体反应、行为选择、环境细节来呈现。**

执行优先级：

```
第一优先  情绪规范（行为替代感受）     → 去AI味效果最显著
第二优先  结尾规范（制造缺口）         → 直接影响读者留存
第三优先  对话规范（说一半不说全）     → 影响角色真实感
第四优先  句式规范（禁用抽象描述）     → 基础语言质量
第五优先  节奏规范（学会偷懒）         → 影响整体阅读体验
```

## 附：StyleEditor 审查 Prompt 核心规则块

可直接加入 StyleEditor 的 system prompt：

```
【去AI味审查规则】

1. 情绪直写检测
   扫描全文，找到所有"感到/感受到/涌起/充满 + 情绪词"的句子。
   发现即标记，要求Writer改为具体的身体反应或行为描写。

2. 抽象修饰词检测
   禁用词列表：复杂的/难以言说的/莫名的/无比/极了
   发现即要求删除或替换为具体描述。

3. 对话完整度检测
   检查是否存在角色连续3句以上完整陈述观点的对话段落。
   发现即要求打断、压缩或改为行为替代。

4. 章节结尾类型检测
   最后一段是否属于：感慨式/总结式/决心式？
   是则退回，要求改为信息钩/行动钩/反转钩之一。

5. 节奏均匀检测
   对比本章的场景类型标注（来自Planner），
   检查铺垫/过渡场景是否有不必要的展开描写。
   发现即要求压缩。
```
