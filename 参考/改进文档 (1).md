# 小说生成 Agent — 深度改进文档

> 基于 CAN (Novel Pipeline - Write Engine) 深度逆向分析报告、6 大 AI 写作项目横向对比及补充建议文档，针对当前「小说生成 Agent」系统提出的系统性改进方案。

## 一、现状差距分析

### 1.1 核心能力对比

| 维度 | 当前项目 | CAN (逆向参考) | 差距评级 |
|------|----------|---------------|---------|
| 质量门禁 | 软性审计（Auditor 输出 risk_level） | 8 步物理硬门禁，任一不过则阻断入库 | ⚠️ 严重 |
| 连续性保证 | 连贯性检查 Agent（LLM 判断） | 正则+关键词的物理证据核验 | ⚠️ 严重 |
| 防水文机制 | 无 | padding_guard + scene_delta_guard 双层 | ⚠️ 严重 |
| 幻觉拦截 | 无 | canon_evidence_guard + hallucination_guard | ⚠️ 严重 |
| 剧情债务管理 | foreshadows 表（被动记录） | pledges/secrets 主动约束注入 Prompt | ❌ 缺失 |
| 读者承诺回收窗口 | 无 | reader_promises 兑现区间管理 | ❌ 缺失 |
| 向量检索防重复 | 余弦相似度召回（无时间打压） | 章节距离打压算法 | ❌ 缺失 |
| 迭代预算保护 | 无 | 5 级降级模式，防 token 耗尽导致状态不一致 | ❌ 缺失 |
| 卷桥接报告 | 无 | volume_bridge.json，跨卷状态固化 | ❌ 缺失 |
| 自动化测试 | 无 | 72 个测试用例覆盖所有门禁 | ❌ 缺失 |
| 模型 Fallback | FallbackLLM（链式尝试） | 7 层中间件管道（含 Thinking 剥离） | 🔶 部分 |
| 状态版本快照 | YAML 快照 | chapter_versions 只增不删版本表 | 🔶 部分 |

### 1.2 当前项目核心痛点

**问题一：质量保证依赖 LLM 自审，无物理兜底**
Auditor Agent 的审计结论本身是 LLM 生成的，当主模型性能不稳定时，审计结论同样不可靠。CAN 系统用正则脚本对正文做静态扫描，与 LLM 无关，不可绕过。

**问题二：上下文承接缺乏可验证的物理证据**
现有 ContinuityCheckerAgent 依赖模型理解，无法核验「本章开头是否真实引用了上章的 Hook 关键词」。CAN 系统对此有精确的字符级匹配算法。

**问题三：向量检索存在复读风险**
当前 vector_store 没有对近期章节做距离惩罚，可能导致模型频繁检索并复述最近 1-3 章内容，造成读者感知重复。

**问题四：长篇无剧情债务约束，后期逻辑崩坏风险高**
当前系统记录伏笔但不主动施加约束，无法防止秘密提前曝光、承诺无限拖延等长篇通病。

**问题五：无 token 预算保护，流水线中途中断导致状态不一致**
Step 14（向量索引）或 Step 15（仪表盘）等收尾步骤如遭遇 token 耗尽，状态写入不完整，下一章 pre 阶段会读到脏数据。

## 二、改进方案

### 改进一：物理质量门禁层（Priority: P0）

#### 背景

CAN 的核心创新不在 Agent 设计，而在于**把质量标准从 Prompt 指令转移到代码逻辑**。每个门禁都是一段独立的 Python 脚本，任何一项不过都阻断章节入库。

#### 目录结构

在 `novel_agent/` 下新增 `quality/` 子包（对应建议文档的命名）：

```
novel_agent/quality/
    __init__.py
    padding_guard.py          # 防水文检测（5 种模式）
    anti_ai_style.py          # 反 AI 腔检测（10 种特征）
    hooks_extractor.py        # 连续性 Hook 提取与核验
    scene_delta.py            # 场景推进度检测
    canon_evidence_guard.py   # 设定幻觉拦截
```

#### 具体实现

**① 防水文守卫 `quality/padding_guard.py`**

采用百分制评分，支持四级判定（none / warning / review / fail），比简单的通过/拦截更灵活：

```python
import re

def check_padding(text: str) -> dict:
    score = 0
    details = []

    # 模式 A：重复解释检测（相邻 3 句词集交集 > 3 词）
    sentences = re.split(r'[。！？\n]', text)
    for i in range(len(sentences) - 2):
        s1 = set(re.findall(r'[\u4e00-\u9fff]{2,4}', sentences[i]))
        s2 = set(re.findall(r'[\u4e00-\u9fff]{2,4}', sentences[i+1]))
        s3 = set(re.findall(r'[\u4e00-\u9fff]{2,4}', sentences[i+2]))
        if len(s1 & s2) > 3 and len(s2 & s3) > 3:
            score += 5
            details.append(f'重复解释: {sentences[i][:20]}...')
            if score >= 25: break  # 上限 25 分

    # 模式 B：空洞内心戏检测（心理动词前后无物理动作）
    psych_pat = re.compile(r'(他|她|我)(知道|明白|意识到|觉得|感觉|想起|想到|感到|认为).{0,30}[。]')
    action_pat = re.compile(r'(走|跑|拿|放|看|站|坐|蹲|劈|搬|推|拉|跳|挥|刺|射)')
    b_score = 0
    for m in psych_pat.finditer(text):
        ctx = text[max(0, m.start()-30):m.end()+30]
        if not action_pat.search(ctx):
            b_score += 3
            details.append('空洞内心戏')
            if b_score >= 20: break  # 上限 20 分
    score += min(b_score, 20)

    # 模式 C：对话回音检测（相邻两段对话词集重合 > 5）
    dialogs = re.findall(r'[""「」].{15,80}[""」]', text)
    c_score = 0
    for i in range(len(dialogs) - 1):
        d1 = set(re.findall(r'[\u4e00-\u9fff]{2,4}', dialogs[i]))
        d2 = set(re.findall(r'[\u4e00-\u9fff]{2,4}', dialogs[i+1]))
        if len(d1 & d2) > 5:
            c_score += 4
            details.append('对话回音')
            if c_score >= 15: break  # 上限 15 分
    score += min(c_score, 15)

    # 模式 D：低增量段落检测（段落无动作/对话/感知/转折/变化）
    paragraphs = [p.strip() for p in text.split('\n') if p.strip()]
    low_count = 0
    action_signals = re.compile(r'(走|跑|拿|说|看|打|[""「」]|发现|突然|但是|然而|变化|改变)')
    for p in paragraphs:
        if not action_signals.search(p):
            low_count += 1
    if low_count > 5:
        d_score = min((low_count - 5) * 2, 25)
        score += d_score
        details.append(f'低增量段落 {low_count} 个')

    # 模式 E：尾部总结检测
    tail = text[-400:]
    if re.search(r'总之|总而言之|总的来说|从此以后|他知道.{0,10}了|她明白.{0,10}了', tail):
        score += 15
        details.append('尾部总结腔')

    # 判定
    if score <= 20:   level = 'none'
    elif score <= 40: level = 'warning'
    elif score <= 60: level = 'review'
    else:             level = 'fail'

    return {
        'pass': level != 'fail',
        'level': level,
        'score': min(score, 100),
        'details': details,
    }
```

**② 反 AI 腔守卫 `quality/anti_ai_style.py`**

10 种中文 AI 写作特征，命中 3+ 处拦截：

```python
import re

AI_PATTERNS = [
    (r'不是.{1,10}而是.{1,10}',          '不是A而是B 对比句式'),
    (r'那一刻.{0,5}(终于|猛然|突然)?明白', '那一刻明白 顿悟模板'),
    (r'(她|他|我)从未想过',               '从未想过 开头套路'),
    (r'(他|她|我)意识到',                 '意识到 过度心理描写'),
    (r'这意味着',                         '这意味着 解释性插入'),
    (r'像一(座|尊|个).{1,8}(一样|般|似的)', '像一座/尊 懒惰比喻'),
    (r'沉默了.{1,3}秒',                   '沉默了N秒 节奏填充'),
    (r'是(她|他|我)的救赎',               '是TA的救赎 AI腔标志'),
    (r'(公式|方程|热力学|量子|熵|牛顿)',   '硬科学引用 网文不该出现'),
    (r'通过.{2,15}实现了|基于.{2,15}进行了', '论文摘要腔'),
]

def check_anti_ai_style(text: str) -> dict:
    matched = []
    for pattern, label in AI_PATTERNS:
        hits = re.findall(pattern, text)
        if hits:
            matched.append({'label': label, 'count': len(hits), 'sample': str(hits[0])})

    count = len(matched)
    if count == 0:   status = 'perfect'
    elif count <= 2: status = 'pass'
    else:            status = 'fail'

    return {
        'pass': status != 'fail',
        'status': status,
        'count': count,
        'matched_patterns': matched,
    }
```

**③ 连续性 Hook 提取与核验 `quality/hooks_extractor.py`**

将 Hook 提取从 LLM 判断前置为正则预检，再把结构化结果注入 LLM Prompt，大幅提升连贯性检查的准确性：

```python
import re

ACTION_HOOKS   = re.compile(r'(正要|准备|打算|决定|即将|就要|刚想|刚准备|开始|试图).{0,15}(?:[。！？\n]|$)')
PERCEPTION_HOOKS = re.compile(r'(发现|察觉|注意|看出|感觉到|意识到|听到|闻到|看到).{0,20}(?:了|到|出)')
INJURY_HOOKS   = re.compile(r'(受伤|流血|伤口|疼痛|晕|昏迷|中毒|发热|发冷|虚弱|透支|内伤|经脉)')
SUSPENSE_HOOKS = re.compile(r'(?:\.{3,}|……|[？?])\s*$')
LOCATION_CHANGE = re.compile(r'(来到|进入|走出|到达|飞往|传送至|回到).{0,15}(?:[。！？\n]|$)')

STATE_PATTERNS = {
    'injuries': re.compile(r'(受伤|流血|伤势|昏迷|中毒)'),
    'items':    re.compile(r'(持有|拿着|手中|怀里|背着)'),
    'tasks':    re.compile(r'(必须|一定要|不能放弃|找到|完成)'),
    'emotions': re.compile(r'(愤怒|恐惧|绝望|喜悦|悲伤)'),
}

def _extract_keywords(text: str) -> list[str]:
    return list(set(re.findall(r'[\u4e00-\u9fff]{2,4}', text)))

def extract_hooks(text: str, tail_chars: int = 400) -> dict:
    """从上章结尾提取结构化 hooks"""
    tail = text[-tail_chars:] if len(text) > tail_chars else text
    return {
        'unfinished_actions': ACTION_HOOKS.findall(tail),
        'perceptions':        PERCEPTION_HOOKS.findall(tail),
        'injuries':           INJURY_HOOKS.findall(tail),
        'suspense_ending':    bool(SUSPENSE_HOOKS.search(tail)),
        'location_changes':   LOCATION_CHANGE.findall(tail),
        'active_states':      {k: bool(pat.search(tail)) for k, pat in STATE_PATTERNS.items()},
        'keywords':           _extract_keywords(tail),
    }

def check_continuity(prev_hooks: dict, current_head: str, head_chars: int = 600) -> dict:
    """核验本章开头是否承接了上章 hooks"""
    head = current_head[:head_chars]
    missing_hooks, forgotten_states = [], []

    # Hook 关键词覆盖率
    total, matched = 0, 0
    for hook_type, values in prev_hooks.items():
        if hook_type in ('keywords', 'active_states', 'suspense_ending') or not values:
            continue
        for keyword in (values if isinstance(values, list) else []):
            total += 1
            if keyword in head:
                matched += 1
            else:
                missing_hooks.append({'type': hook_type, 'keyword': keyword})

    # 状态遗忘检测
    for state, active in prev_hooks.get('active_states', {}).items():
        if active and not STATE_PATTERNS[state].search(head):
            forgotten_states.append(state)

    hook_coverage = matched / max(total, 1)
    state_score = 1.0 - len(forgotten_states) / len(STATE_PATTERNS)
    total_score = hook_coverage * 0.5 + state_score * 0.3 + 0.2

    return {
        'pass': len(missing_hooks) <= 1 and len(forgotten_states) <= 1 and total_score >= 0.65,
        'score': round(total_score, 3),
        'hook_coverage': round(hook_coverage, 3),
        'missing_hooks': missing_hooks,
        'forgotten_states': forgotten_states,
    }
```

**集成到 ContinuityCheckerAgent**：在发送给 LLM 之前，先调用 `extract_hooks()` + `check_continuity()`，将结构化结果注入 Prompt：

**④ 场景推进度守卫 `quality/scene_delta.py`**

```python
import re

SCENE_SPLIT = re.compile(
    r'(?:第二天|次日|天亮|天黑|黎明|黄昏|入夜|三日后|半月后'
    r'|来到|进入|走出|回到|飞往|离开|到达'
    r'|\*{3}|---)'
)

DELTA_DIMS = {
    'plot':         re.compile(r'发现|揭露|得知|出现|发生|遭遇|获得|失去'),
    'char_state':   re.compile(r'决定|改变|选择|放弃|接受|觉醒|突破'),
    'relationship': re.compile(r'信任|怀疑|背叛|结盟|爱上|仇恨|和解|反目'),
    'conflict':     re.compile(r'战斗|对峙|威胁|追杀|逃离|对抗|击败|受伤'),
    'worldbuilding':re.compile(r'规则|法则|禁制|秘境|势力|宝物|功法'),
    'reader_promise':re.compile(r'承诺|发誓|约定|复仇|报恩|欠下'),
    'next_hook':    re.compile(r'然而|但是|忽然|突然|没想到|谁知|岂料'),
}

def check_scene_delta(text: str, short_chapter: bool = False) -> dict:
    scenes = [s.strip() for s in SCENE_SPLIT.split(text) if len(s.strip()) > 100]
    if not scenes:
        scenes = [text]

    valid, low = 0, 0
    scene_reports = []
    for scene in scenes:
        active_dims = [dim for dim, pat in DELTA_DIMS.items() if pat.search(scene)]
        if len(active_dims) >= 2:
            valid += 1
        else:
            low += 1
        scene_reports.append({'active_dims': active_dims, 'length': len(scene)})

    min_valid = 1 if short_chapter else 3
    return {
        'pass': valid >= min_valid and low <= 1,
        'valid_scenes': valid,
        'low_delta_scenes': low,
        'scene_reports': scene_reports,
    }
```

**⑤ 设定幻觉守卫 `quality/canon_evidence_guard.py`**

```python
import re

HARD_CLAIM_PATTERNS = {
    'realm_change': re.compile(r'(突破|晋升|踏入|进阶).{0,10}(境界|层次|级别|阶段)'),
    'new_faction':  re.compile(r'(?:一个|某个).{0,5}(?:门派|势力|组织|家族).{0,10}(?:出现|诞生|崛起)'),
    'new_item':     re.compile(r'(得到|获得|发现).{0,10}(法宝|神器|秘籍|功法)'),
    'betrayal':     re.compile(r'(背叛|投靠|倒戈|出卖).{0,15}(?:了|道|地)'),
}

def check_canon(text: str, task_card: dict, prev_brief: str) -> dict:
    hard_claims = []
    for claim_type, pat in HARD_CLAIM_PATTERNS.items():
        for m in pat.finditer(text):
            hard_claims.append({'type': claim_type, 'text': m.group()})

    allowed_sources = task_card.get('allowed_new_canon', []) + [prev_brief]
    unsupported = []
    for claim in hard_claims:
        keywords = re.findall(r'[\u4e00-\u9fff]{2,4}', claim['text'])
        has_evidence = any(
            any(kw in src for kw in keywords)
            for src in allowed_sources
        )
        if not has_evidence:
            unsupported.append(claim)

    total = len(hard_claims)
    coverage = 1.0 - len(unsupported) / max(total, 1)
    return {
        'pass': coverage >= 0.85 and len(unsupported) == 0,
        'evidence_coverage': round(coverage, 3),
        'unsupported_hallucinations': unsupported,
        'total_hard_claims': total,
    }
```

### 改进二：Reader Promises — 读者承诺与剧情债务管理（Priority: P1）

#### 背景

当前 `foreshadows` 表是被动记录（记录伏笔的存在），缺少两个关键能力：
- **回收窗口管理**：哪个承诺必须在第几章到第几章之间兑现
- **信息禁令**：哪个秘密在特定章节前绝对不能泄露

#### 数据表设计

在 `state/sqlite_store.py` 的 `_init_schema()` 中新增三张表：

```sql
-- 读者承诺（含回收窗口）

    novel_id             TEXT NOT NULL,
    title                TEXT NOT NULL,
```

#### Prompt 动态注入

在 `agents/context_builder.py` 组装阶段，追加债务约束块：

```python
def build_narrative_debt_block(current_chapter: int, novel_id: str, db) -> str:
    # 即将到期的承诺（deadline 在当前章 ±3 章内）
    urgent_pledges = db.execute("""
        SELECT description, deadline_ch FROM pledges
        WHERE novel_id=? AND status='open' AND deadline_ch BETWEEN ? AND ?
    """, (novel_id, current_chapter - 1, current_chapter + 3)).fetchall()

    # 进入回收窗口的 reader_promises
    due_promises = db.execute("""
        SELECT title, description, expected_payoff_range, priority FROM reader_promises
        WHERE novel_id=? AND status='open'
    """, (novel_id,)).fetchall()
    import json
    overdue = [p for p in due_promises
               if json.loads(p['expected_payoff_range'] or '[0,9999]')[0] <= current_chapter]

    # 当前仍保密的秘密
    sealed = db.execute("""
        SELECT description FROM secrets
        WHERE novel_id=? AND status='sealed' AND forbidden_until_ch > ?
    """, (novel_id, current_chapter)).fetchall()

    block = "\n## 剧情债务约束（必须遵守）\n"
    if sealed:
        block += "\n### ⛔ 信息禁令（本章绝对不可揭露）\n"
        for s in sealed:
            block += f"- {s['description']}\n"
    if urgent_pledges:
        block += "\n### ⏰ 即将到期承诺\n"
        for p in urgent_pledges:
            tag = "【本章必须推进】" if p['deadline_ch'] <= current_chapter else "【即将到期】"
            block += f"- {tag} {p['description']}（截止第{p['deadline_ch']}章）\n"
    if overdue:
        block += "\n### 📌 已进入回收窗口的读者承诺\n"
        for p in sorted(overdue, key=lambda x: -x['priority']):
            block += f"- [优先级{p['priority']}] {p['title']}：{p['description']}\n"
    return block
```

### 改进三：向量检索时间距离打压（Priority: P1）

#### 背景

当前 `context_builder.py` 直接按余弦相似度召回历史片段，没有对近期章节做惩罚。读者刚读过的内容被 LLM 再次检索并复述，产生强烈重复感。

#### 实现

修改 `state/vector_store.py`：

```python
def retrieve_with_distance_penalty(
    self, query: str, current_chapter: int, top_k: int = 5
) -> list[dict]:
    """
    ΔC ≤ 3  : 丢弃（读者刚读过）
    ΔC 3-5  : 保留，打标 REQUIRE_REWRITE_40%
    ΔC > 5  : 正常采纳
    wiki    : 永远优先采纳，不受距离限制
    """
    raw = self.retrieve(query, top_k=top_k * 3)
    filtered = []
    for chunk in raw:
        delta = current_chapter - chunk.get('chapter_id', 0)
        if chunk.get('source_type') == 'wiki':
            chunk['rewrite_hint'] = None
        elif delta <= 3:
            continue
        elif delta <= 5:
            chunk['rewrite_hint'] = 'REQUIRE_REWRITE_40%'
        else:
            chunk['rewrite_hint'] = None
        filtered.append(chunk)
        if len(filtered) >= top_k:
            break
    return filtered
```

在 `ContextBuilderAgent` 组装时注入提示：

```python
for chunk in retrieved:
    if chunk.get('rewrite_hint') == 'REQUIRE_REWRITE_40%':
        context += "\n[注意：以下内容来自近期章节，引用时须改写措辞，不可原文复述]\n"
    context += f"[第{chunk.get('chapter_id','?')}章] {chunk['content']}\n"
```

### 改进四：7 层 LLM 中间件管道（Priority: P2）

#### 背景

当前 `FallbackLLM` 只做链式重试，缺少 Thinking 链剥离（DeepSeek-R1 输出含 `<think>` 标签会污染正文）、API Key 轮换和结构化日志。

#### 实现

重构 `agents/base.py` 的 `OpenAILLM`：

```python
import re

class RobustLLMClient:
    """7 层中间件 LLM 客户端"""

    def __init__(self, config: dict):
        self.config = config
        self.key_pool = config.get('api_keys', [config.get('api_key')])
        self.key_index = 0

    async def generate(self, role: str, prompt: str) -> 'LLMResult':
        api_key = self._rotate_key()                      # Layer 1: Key 轮换
        try:
            raw = await self._call_api(api_key, prompt)
        except RateLimitError:
            api_key = self._rotate_key(force=True)        # Layer 2: 限频切换 Key
            raw = await self._call_api(api_key, prompt)
        except Exception as e:
            raw = await self._fallback_call(prompt, e)    # Layer 3: 模型降级

        thinking, content = self._extract_thinking(raw)   # Layer 4: Thinking 剥离
        parsed = self._parse_structured(content)          # Layer 5: JSON 修复解析
        self._log_usage(role, raw.usage, thinking)        # Layer 6: Token 统计
        self._validate_output(content, role)              # Layer 7: 完整性校验

        return LLMResult(content=content, thinking=thinking, usage=raw.usage)

    def _extract_thinking(self, raw) -> tuple[str, str]:
        """剥离 <think>…</think>，归档供调试，正文区只保留纯净文本"""
        content = raw.choices[0].message.content or ''
        pat = re.compile(r'<think>(.*?)</think>', re.DOTALL)
        thinking = '\n'.join(pat.findall(content))
        return thinking, pat.sub('', content).strip()

    def _rotate_key(self, force: bool = False) -> str:
        if force:
            self.key_index = (self.key_index + 1) % len(self.key_pool)
        return self.key_pool[self.key_index]
```


### 改进五：迭代预算保护（Priority: P2）

#### 背景

流水线在 Step 14（向量索引）或 Step 15（仪表盘）等收尾步骤遭遇 token 耗尽，会导致状态写入不完整，下一章 pre 阶段读到脏数据。

#### 实现

在 `novel_agent/pipeline.py` 新增 `BudgetTracker`：

```python
class BudgetTracker:
    """Token 预算追踪器，驱动流水线分级降级"""

    MODES = [
        (0.50, 'normal'),    # > 50% 剩余：全流程
        (0.30, 'shrink'),    # 30-50%：跳过 dashboard、vector_index
        (0.15, 'wrap_up'),   # 15-30%：只保 state_update
        (0.08, 'freeze'),    # < 15%：保存 checkpoint，输出交接
        (0.00, 'readonly'),  # < 8%：只读，严禁任何写入
    ]

    SKIP_MAP = {
        'shrink':   {'dashboard', 'vector_index'},
        'wrap_up':  {'dashboard', 'vector_index', 'style_editor', 'chapter_summary'},
        'freeze':   '__all__',
        'readonly': '__all__',
    }

    def __init__(self, estimated_total: int):
        self.total = estimated_total
        self.used = 0

    def record(self, tokens: int):
        self.used += tokens

    @property
    def remaining_ratio(self) -> float:
        return max(0.0, 1.0 - self.used / self.total)

    @property
    def mode(self) -> str:
        ratio = self.remaining_ratio
        for threshold, mode in self.MODES:
            if ratio > threshold:
                return mode
        return 'readonly'

    def should_skip(self, step: str) -> bool:
        skip = self.SKIP_MAP.get(self.mode, set())
        return skip == '__all__' or step in skip

    def checkpoint_summary(self) -> dict:
        return {
            'mode': self.mode,
            'used_tokens': self.used,
            'remaining_ratio': round(self.remaining_ratio, 3),
            'next_prompt': '从上次 checkpoint 恢复，重新运行 Step 13 之后的步骤',
        }
```

在 `orchestrator.py` 各步骤前加判断：

```python

    logger.warning("预算不足，跳过 Step 14 向量索引")
else:
    await self._run_vector_index(chapter_text)
```

```python
# sqlite_store.py
def create_version(self, chapter_id: str, title: str, content: str,
                   word_count: int, guard_results: dict = None,
                   status: str = 'draft', change_reason: str = '') -> int:
    row = self.conn.execute(
        "SELECT COALESCE(MAX(version_no), 0) FROM chapter_versions WHERE chapter_id=?",
        (chapter_id,)
    ).fetchone()
    next_v = row[0] + 1
    self.conn.execute(
        "UPDATE chapter_versions SET is_current=0 WHERE chapter_id=?", (chapter_id,)
    )
    import json
    self.conn.execute(
        "INSERT INTO chapter_versions (novel_id, chapter_id, version_no, title, content, "
        "word_count, guard_results, status, change_reason, is_current) "
        "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, 1)",
        (self.novel_id, chapter_id, next_v, title, content,
         word_count, json.dumps(guard_results or {}), status, change_reason)
    )
    self.conn.commit()
    return next_v
```

```python
def check_paragraph_layout(text: str) -> dict:
    paragraphs = [p.strip() for p in text.split('\n') if p.strip()]
    long_paras = [p for p in paragraphs if len(p) > 150]
    ratio = len(long_paras) / max(len(paragraphs), 1)
    return {
        'pass': ratio < 0.3,
        'long_paragraph_ratio': round(ratio, 3),
        'long_paragraph_count': len(long_paras),
```
