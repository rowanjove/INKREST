# 六、一个更锋利的判断标准

别只看“题材名”，要看**主爽点**。

同样是“修仙”：

| 类型 | 真正卖点 |
|---|---|
| 男频修仙 | 升级、夺宝、长生、杀伐、宗门、世界观 |
| 女频修仙 | 师徒、宿命、虐恋、女强、身份、救赎 |
| 无CP修仙 | 成长、道心、事业、飞升，不靠恋爱驱动 |
| 纯爱修仙 | 双男主关系、师门、仙魔、强强 |
| 百合修仙 | 双女主关系、仙门、宿命、救赎 |

同样是“都市”：

| 类型 | 真正卖点 |
|---|---|
| 男频都市 | 赚钱、装逼、打脸、神豪、兵王、神医 |
| 女频都市 | 恋爱、婚姻、职场、豪门、救赎、成长 |
| 现实都市 | 行业、家庭、社会议题、职业成长 |
| 都市异能 | 超能力带来的阶层跃迁 |

同样是“历史”：

| 类型 | 真正卖点 |
|---|---|
| 男频历史 | 争霸、制度、科技、战争、权谋 |
| 女频古言 | 婚姻、家族、宅斗、宫斗、身份改命 |
| 大女主历史 | 掌权、治国、女帝、权谋 |
| 种田古代 | 发家致富、家庭经营、生活改善 |

所以你真要做小说分类库，不要只建“玄幻/都市/古言”这种粗分类。应该至少用四层：

```text
频道：男频 / 女频 / 纯爱 / 百合 / 无CP / 多元
题材壳：玄幻 / 都市 / 古代 / 现代 / 星际 / 末世 / 历史
机制：重生 / 穿越 / 系统 / 快穿 / 无限 / 经营 / 直播 / 马甲
爽点：升级 / 打脸 / 复仇 / 甜宠 / 虐恋 / 权谋 / 种田 / 救赎 / 破镜重圆
```

这套比单纯平台分类更好用，因为现在网文基本都是混合型。比如：

```text
女频 + 古代 + 穿书 + 种田 + 养崽 + 先婚后爱
男频 + 玄幻 + 反派 + 系统 + 家族流 + 苟道
女频 + 现代 + 真假千金 + 玄学直播 + 马甲 + 打脸
男频 + 科幻 + 末世 + 囤货 + 基地经营 + 异能
纯爱 + 无限流 + 强强 + 规则怪谈 + 破镜重圆
```

这才是现在市场真实在跑的分类逻辑。
