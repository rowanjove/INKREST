# 栖墨插件包模板

1. 将 `id` 改为唯一小写标识（与文件夹名一致更佳）
2. 修改 `plugin_type` 与 `plugin.py` 中的基类
3. 核对 `capabilities`，只声明实际需要的权限；未知或重复权限会被拒绝
4. 整个目录打成 zip（根目录须含 `inkrest.plugin.json`）
5. 在应用 **扩展中心** 点击 **载入插件** 上传

安装、更新或权限变化后，用户都需要按当前 SHA-256 内容摘要重新确认信任。
信任与启用是两个独立动作。

可选：`bundles` 引用包内其它 zip；`extract` 在安装时解压到 `data/` 子目录。
