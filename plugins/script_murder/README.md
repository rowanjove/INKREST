# 墨局 · 剧本杀工坊

这是 Inkrest 的独立剧本杀创作插件。它把 Truth Canon、人物认知边界、线索/结论图和三轮流程作为结构化源数据，再生成玩家剧本、主持人手册、线索卡和可打印开本包。

## 使用

1. 在插件管理器安装 ZIP，并在信任提示中授予 `model_access`、`file_export`、`web_routes`、`ui_embed`。
2. 从左侧「剧本工坊」创建项目；先编辑或生成真相板，再依次处理人物、线索/结论和流程。
3. AI 节点是可取消、可追踪的后台任务。工坊发起的生成先进入候选区，确认“接受”后才写入项目；每次结构编辑都会增加 revision，并将依赖的文稿、审计和导出标记为 `stale`。
4. 在「质量」运行确定性验证、语义审计和有限信息试玩；「导出」会执行 Preflight，只有完整且没有过期派生物时才生成 ZIP。

插件在没有有效模型配置时使用确定性的离线 fixture，便于本地验收；检测到真实模型配置后，模型错误会显式暴露为任务失败，不会静默伪造成功结果。

## 数据与恢复

项目数据存放于应用根目录的 `data/plugins/script_murder/`。删除操作先移动到插件回收区，可通过 API 或后续回收区界面恢复；`source/` 中的 JSON 和 `export_manifest.json` 用于继续编辑与完整性校验。
